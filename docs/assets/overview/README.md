# Screenshot provenance

Captured on 2026-09-17 in native Mobile Safari on a disposable iPhone 17 Pro
simulator running iOS 27 (1206 × 2622 pixels). All content is original demo text.
Only the generic loopback name `localhost` appears; no LAN host, user account,
production certificate, password or publisher content was used. EXIF and text
metadata were removed without changing the original captures' image data.

- `01-rescue-button.png`: the real userscript detector on a large scroll-triggered
  demonstration wall. The fixture supplies the manager's two storage APIs.
- `02-reader-home.png`: the actual reader HTML, including the certificate links.
- `03-reader-article.png`: the actual Readability/DOMPurify reading view after
  receiving a deterministic HTML response from the local demo API.
- `iphone-overview.png`: an AI-assisted framed and annotated overview of those
  captures. Use the three original PNGs for exact UI inspection.

A native XCTest run separately verified scrolling, button detection, the tap,
and the readable result. These screenshots are not a live publisher-fetch test
or a new test of installing the Userscripts extension; installation has its own guide.
