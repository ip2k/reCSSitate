iPhone / iPad instructions · Mac instructions

On iPhone or iPad

  1. Download in Safari

    Tap Download this reader’s CA certificate, choose Allow, then Close on the Profile Downloaded message.

  2. Open Settings

    Tap Profile Downloaded. If it is missing, go to General → VPN & Device Management. Install within eight minutes; otherwise, download it again.

  3. Install the certificate

    Check the certificate’s identity in More Details, then tap Install. Enter your iPhone unlock passcode if asked, confirm Install, then tap Done.

  4. Find the trust settings

    Go to Settings → General → About, scroll down, and tap Certificate Trust Settings.

  5. Enable full trust

    Turn on the switch for your reader’s root certificate under Enable Full Trust for Root Certificates. Tap Continue to confirm. Caddy’s default name usually begins with Caddy Local Authority.

  6. Open the reader

    Open your HTTPS reader

    Return to Safari and open the reader’s HTTPS address. The warning should be gone. Sign in only if your administrator enabled authentication; it is off by default.

On a Mac

  1. Download this reader’s CA certificate and save it in Downloads. Confirm its name and SHA-256 fingerprint with your administrator.
  2. Open Keychain Access using Spotlight (Command–Space). If macOS offers Passwords, choose Open Keychain Access.
  3. Select System in the sidebar. Choose File → Import Items… and open the downloaded certificate. Authenticate with your Mac administrator credentials if asked.
  4. In Certificates, double-click your imported root. Expand Trust and set When using this certificate to Always Trust.
  5. Close the certificate window to save and authenticate if prompted. Reopen the HTTPS reader in Safari; the warning should be gone.

Still seeing a warning?

Check that full trust is on and that the address matches the server certificate. A name mismatch or expired certificate needs a server fix. If the server’s CA changes, install and trust its new certificate.

To remove a root later, open Settings → General → VPN & Device Management, select its profile, and choose Remove Profile.
